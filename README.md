# Spr1ngChkn.info
A Basic React Stack developed with D2G on Koder. 

## Features

### Instagram Video Embed
This stack includes an experimental component called "InstagramVideoEmbed" to learn about **iframes** and embedding.

### Repository Creation Form
A new feature that allows users to create GitHub repositories directly from the web interface. The form includes:
- Repository name input
- Description textarea
- Private/Public toggle
- Form validation

This web app is accessible on iOS devices through any modern browser, making it easy to manage repository creation on the go.
